Conoce las asociaciones estudiantiles y tecnológicas participantes en las jornadas de la Universidad Pablo de Olavide.

Asociación de Programación

Las principales áreas de trabajo son:

  • Programación
    1. Python
    2. Java
    3. JavaScript
  • Desarrollo web y aplicaciones móviles
  • Proyectos de código abierto colaborativos

Asociación de Robótica

La asociación desarrolla proyectos de robótica aplicada, electrónica y automatización industrial.

  1. Diseño del proyecto
  2. Construcción del prototipo
  3. Programación de microcontroladores
  4. Pruebas de funcionamiento y validación

Asociación de Videojuegos

Las áreas de trabajo principales abarcan el desarrollo integral de videojuegos y entretenimiento interactivo:

  • Programación y motores de juego
  • Diseño de niveles y mecánicas
  • Diseño gráfico 2D y modelado 3D
  • Composición de sonido y contenidos digitales
